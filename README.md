# productOperands

ProductOperands

This is novel algorithm to find the multiplier,multiplicand of the given product.
The operands are natural numbers

ProductOperandsOddPrimes

This is novel algorithm to find the multiplier,multiplicand of the given product.
The operands are odd prime numbers
In version v2,instead of finding operands from 1, it starts with the square root of product,

It is based on formula
(((a+b)/2)^2)-(((a-b)/2)^2)=ab

I have implemented in python,java,javascript.
